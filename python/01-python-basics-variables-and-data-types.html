1.1 What is Python?

  • Python is a high-level, interpreted, and general-purpose programming language.
  • It was created by Guido van Rossum and first released in 1991.
  • Python is known for its readability and simplicity, which makes it an excellent choice for beginners and experienced developers alike.
  • It has a large and active community, providing extensive libraries and frameworks for various applications.

1.1.1 Python Interpreters

  • Python provides different ways to interact with the language, including interactive shells and integrated development environments (IDEs).
  • IDLE: IDLE is a simple integrated development environment that comes bundled with Python. It provides a Python shell where you can execute code interactively and write scripts.
  • Jupyter Notebook: Jupyter Notebook is a web-based interactive computing environment that allows you to create and share documents containing live code, equations, visualizations, and narrative text. It’s widely used for data analysis and data science tasks.

1.2 Variables and Data Types

1.2.1 Numeric Types

  • Integers (int): Integers are whole numbers without a decimal point. For example, 5 and -10 are integers.
  • Floats (float): Floats represent real numbers with a decimal point. Examples include 3.14 and -0.5.
  • Complex Numbers (complex): Complex numbers consist of a real part and an imaginary part. For instance, 3 + 2j is a complex number.

1.2.2 Strings and String Manipulation

  • Strings (str): Strings are sequences of characters enclosed in single (’ ‘), double (” “), or triple (’’’ ’’’ or”“” “““) quotes. Examples:”Hello, Python!” or ’12345’.
  • String Manipulation: Python provides various methods and operators for manipulating strings, such as concatenation, slicing, indexing, and formatting.

1.2.3 Lists, Tuples, and Dictionaries

  • Lists (list): Lists are ordered collections of items enclosed in square brackets [ ]. They can contain elements of different data types and are mutable (can be modified).
  • Tuples (tuple): Tuples are similar to lists but enclosed in parentheses ( ). They are immutable (cannot be changed after creation).
  • Dictionaries (dict): Dictionaries are unordered collections of key-value pairs enclosed in curly braces { }. Keys are unique, and they are used to access values. Dictionaries are mutable.

1.2.4 Variables, Assignments, and Basic Operators

  • Variables: Variables are used to store data in Python. You can assign values to variables using the assignment operator (=). For example: x = 10 assigns the value 10 to the variable x.
  • Basic Operators: Python supports various operators for performing operations on variables and values. Common operators include:
    • Arithmetic operators (+, -, *, /, // for floor division, % for modulo)
    • Comparison operators (==, !=, <, >, <=, >=)
    • Logical operators (and, or, not)
    • Assignment operators (+=, -=, *=, /=, etc.)
    • Membership operators (in, not in) for checking if an element is in a container
    • Identity operators (is, is not) for comparing object identity
